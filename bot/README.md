# کانال اخبار بات (@glmfpsbot) — تلگرام + بله

بات @glmfpsbot دیگر بازی را سرو نمی‌کند (نسخه Mini App به درخواست صاحب بات حذف شد).
وظیفه فعلی بات: **خبرنامه رسمی بازی GLM FPS** — اعلام آپدیت‌های جدید به کاربرانی که به بات START داده‌اند و همچنین به کانال‌هایی که بات در آن‌ها ادمین است.

## دو پلتفرم: تلگرام + بله (bale.ai)

ناشر خبر دو-باتی است (اسکریپت `scripts/bot_news.py`، جدول `BOTS`):

| پلتفرم | API base | نکته |
|---|---|---|
| تلگرام | `api.telegram.org` | چت مالک همیشه در مشترکین می‌ماند |
| بله | `tapi.bale.ai` | چت‌آی‌های بله با تلگرام فرق دارد؛ مالک با /start خودش ثبت می‌شود |

- هر بات state جدا دارد: زیر کلید `"bots"` در `/home/z/my-project/bot_state.json` (update_offset / subscribers / channels / channel_titles / sent_news). کلیدهای قدیمی سطح بالای فایل به‌عنوان آینه‌ی بات تلگرام حفظ شده‌اند.
- خبرهای قدیمی (#1..#22) به بله ارسال نشدند — `sent_news` بله با همان 1..22 مقداردهی شد تا بک‌لاگ قدیمی اسپم نشود؛ فقط خبرهای جدید به هر دو پلتفرم می‌رود.
- پاسخ `/start`: هر دو بات به /start توضیح کامل بازی را می‌فرستند (`START_TEXT`).
- اجرای دوره‌ای: cron job «GLM FPS bot worker (Telegram+Bale)» روزی ۳ بار (سقف پلتفرم) `bot_news.py` را یک پاس اجرا می‌کند؛ چون `getUpdates` آپدیت‌ها را سمت سرور نگه می‌دارد و offset ذخیره می‌شود، هیچ پیامی گم نمی‌شود — فقط جواب /start و خوش‌آمد کانال ممکن است تا ~۸ ساعت تأخیر داشته باشند. خبرهای ریلیز همیشه دستی و همان لحظه‌ی ریلیز ارسال می‌شوند. اجرای دستی هم آزاد است (فقط ممکن است هم‌زمانی با cron یک poll خطای 409 بگیرد که بی‌ضرر است).

## گردش کار انتشار خبر (برای هر ریلیز جدید)

1. یک entry جدید به `bot/news.json` اضافه کن (id عددی صعودی، date به‌صورت ISO، version، text فارسی).
2. `git add -A && git commit && git push` — خبر باید همراه خود ریلیز پوش شود.
3. اسکریپت `/home/z/my-project/scripts/bot_news.py` را اجرا کن:
   - همه چت‌های جدید از `getUpdates` را به لیست مشترکین (state لوکال: `/home/z/my-project/bot_state.json`) اضافه می‌کند
   - هر entry که هنوز ارسال نشده را به همه مشترکین **و همه کانال‌های متصل** می‌فرستد و id آن را در state ثبت می‌کند (idempotent — اجرای مجدد چیزی دوباره نمی‌فرستد)
   - کاربرانی که بات را بلاک کرده‌اند (403) از مشترکین حذف می‌شوند

## اتصال کانال

- بات را به‌عنوان **ادمین** به کانال اضافه کن (حداقل با دسترسی «ارسال پیام»).
- به‌محض اضافه شدن، بات خودش را ثبت می‌کند و یک پیام خوش‌آمد + آخرین خبر منتشرشده را در همان کانال پست می‌کند.
- از این به بعد هر خبر جدید علاوه بر چت خصوصی مشترکین، در همه کانال‌های متصل هم پست می‌شود.
- اگر بات از کانال حذف/کیک شود یا کانال پاک شود، کانال به‌صورت خودکار از لیست ارسال حذف می‌شود (خطاهای دائمی: kicked / not a member / chat not found).
- خطای موقتی (مثل نداشتن موقت دسترسی ارسال) کانال را حذف نمی‌کند؛ فقط لاگ می‌شود تا دفعه بعد دوباره تلاش شود.
- تشخیص اضافه شدن: آپدیت `my_chat_member` (وضعیت administrator/member) + به‌عنوان پشتیبان، `channel_post`ها.
- تفاوت بله: بله آپدیت `my_chat_member` نمی‌فرستد، پس اد کردن بات در کانال برای `getUpdates` نامرئی است. دو راه ثبت: ۱) یک پست در کانال بگذار — در اولین اجرای worker از طریق `channel_post` خودکار ثبت می‌شود؛ ۲) فوری و بدون نیاز به پست: `python3 scripts/register_bale_channel.py @username` (با `getChat` رزول می‌کند، ثبت می‌کند و بلافاصله خوش‌آمد + آخرین خبر را پست می‌کند). آیدی کانال‌های بله مثبت است (مثل 5467262750) نه فرمت ‎-100… تلگرام.

## نکات

- توکن بات داخل اسکریپت‌هاست؛ هرگز در مخزن عمومی قرار نگیرد.
- state مشترکین و کانال‌ها فقط لوکال می‌ماند (حریم خصوصی؛ در ریپو ذخیره نمی‌شود).
- حذف entry از news.json تاثیری روی پیام‌های ارسال‌شده ندارد؛ برای اصلاح، entry جدید با id بالاتر بفرست.
- برای ارسال مجدد دستی یک خبر قدیمی (بدون خراب کردن idempotency): `python3 scripts/telegram_resend_news.py [id]`
